# AO-saturated scene that also SATURATES THE CROSS-SHIP MERGE.
#
# ao_cover.txt is deliberately one ship, which isolates the per-fragment path but means every number
# taken on it describes the merge's cheapest case: one host lattice, no partners, no claim lookups.
# The host loop runs once. That is not the configuration the merge is expensive in.
#
# Here the same kind of block lattice is split into 49 SEPARATE single-block ships spaced 2 apart.
# A 2-block spacing puts the voxel-centre AABB gap at 2.0, inside SEAM_G_FULL (2.2), so every
# neighbour claim saturates at 1; the four axis neighbours plus four diagonals at gap 2.83 give each
# interior hull EIGHT candidate partners, of which the directory keeps the top MAX_PARTNERS = 4. So
# every interior fragment builds the full four host lattices and walks the cell's sub-runs once per
# host -- the worst case the per-fragment path has.
#
# Used by autotest/perf_aomerge.sh to attribute what merging costs and what the distance LOD gives
# back. Not scored for correctness; ao_merge and ao_misalign do that.
