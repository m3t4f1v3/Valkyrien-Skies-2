# Hold an AO-saturated scene steady, so an external GPU profiler can attach and trace it.
#
# Same lattice as ao_cover: blocks spaced so their shadows tile the ground, meaning nearly every
# visible fragment does real seam-AO work. The difference is the long tail of waits at the end --
# the client keeps rendering the identical frame for a couple of minutes, which is the window
# autotest/ngfx_trace.sh attaches Nsight to.
#
