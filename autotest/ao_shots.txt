# The merging situations, framed to FILL the shot.
#
# Separate from ao_merge/ao_misalign on purpose. Those sit 13 blocks up so the floor samples close to
# uniformly under the perspective projection, which is what a floor integral needs and what makes the
# numbers in score_ao/ref_merge trustworthy -- but it leaves the shadow as a small patch in a big
# frame. This fixture is the other trade: camera as low as the situation allows, square 1:1 render,
# nothing else in view.
#
# Run this through autotest/ao_shots.sh, which sets the FOV and the square render size the heights
# below assume. Two traps, both of which produced a tiny scene in a wide frame on the first attempt:
#
#   * MC's fov option is a DELTA FROM 70 DEGREES normalised to +/-1 -- not degrees, and not 0..1 over
#     the slider range either. The instance ships fov:1.0, which is 110 degrees. -1.0 is 30, the
#     narrowest the game offers.
#   * overrideWidth/Height do nothing in this setup, silently: the client stays 854x480 whatever they
#     say. Going fullscreen inside gamescope is what works, and then AUTOTEST_W/H set the resolution
#     and the aspect ratio together.
#
# At fov 30 (AUTOTEST_FOV=-1.0) a camera h blocks above the floor sees 0.536*h blocks across a square
# frame. Narrow FOV rather than a low camera on purpose: it zooms optically instead of adding
# perspective distortion to the very pattern being looked at.
#   pair-sized scenes span ~3.5 blocks -> 8 blocks up  (y=-52) shows 4.3, about 82% full
#   the one-block-gap scene spans ~5.5 -> 12 blocks up (y=-48) shows 6.4, about 86% full
world autotest
wait-level
wait 100
hud off
cmd gamemode spectator
cmd time set noon
cmd gamerule doDaylightCycle false
cmd kill @e[type=!player]
wait 20
paint 5
wait 20

# ---- reference: one ship alone, and both cells as ONE ship --------------
# Centred on the pair's midpoint (x=3.0, z=3.5) so every pair-sized case below shares this framing.
cmd tp @s 3.0 -52 3.5 0 90
wait 60
run ao_ship 0 2 -60 3 0:0:0
wait 90
screenshot shot_single
run ao_clear
wait 40
run ao_ship 0 2 -60 3 0:0:0,1:0:0
wait 90
screenshot shot_two_one_ship
run ao_clear
wait 40

# ---- two SEPARATE ships: touching, then sliding off-grid ----------------
run ao_ship 0 2 -60 3 0:0:0
run ao_ship 1 3 -60 3 0:0:0
wait 90
screenshot shot_pair_touching
run ao_pose 1 0 0 0.25 0
wait 60
screenshot shot_pair_off025
run ao_pose 1 0 0 0.5 0
wait 60
screenshot shot_pair_off050
run ao_clear
wait 40
